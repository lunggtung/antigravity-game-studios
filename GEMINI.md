# Antigravity Game Studios

Turn Google Antigravity into a full autonomous game development studio.
49 agents. 73 skills. 11 path-scoped rules. 38 document templates. One coordinated AI team.

## Getting Started
- Run `/start` to onboard your game project.
- Run `/help` to browse all 73 game studio slash commands.
- Run `/setup-engine` to configure your target engine (Godot 4, Unity, or Unreal Engine 5).

## Key Workflows
- **Game Design**: `/brainstorm` -> `/design-system` -> `/art-bible`
- **Architecture**: `/create-architecture` -> `/create-control-manifest`
- **Pre-Production Gate**: `/prototype` -> `/vertical-slice` (PROCEED / PIVOT / KILL)
- **Agile Production**: `/create-epics` -> `/create-stories` -> `/dev-story` -> `/story-done`
- **Team Orchestration**: `/team-combat`, `/team-narrative`, `/team-ui`, `/team-level`, `/team-audio`, `/team-qa`
- **QA & Release**: `/qa-plan` -> `/regression-suite` -> `/balance-check` -> `/release-checklist`

## Antigravity MCP Integrations
- **godot-mcp-toolkit / godot-ai**: Direct node tree manipulation, headless playtesting, and input simulation.
- **pixellab**: Autonomous pixel art generation (characters, animations, tilesets, UI assets).
